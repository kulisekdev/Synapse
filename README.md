## 🌌 About

Synapse is a Python Discord bot with community features, moderation tools, member logging, and a few fun commands. It uses **discord.py** and **MongoDB** to handle bot events and store user stats.

### ⚠️ Built for one server

Synapse was originally made for **my own Discord server**. It is currently configured around that server and is **not a ready-to-run, multi-server bot**. Some channel, role, and server IDs are hardcoded in the code, so you will need to change those values and review the settings before running it on your own server.

You're welcome to **download, modify, and adapt the project for your own needs**. You don't have to keep my server's setup or use every feature. If you improve something, feel free to share the changes or open an issue.

| Feature | What it does |
| --- | --- |
| 📈 **Levels & XP** | Track user XP and levels, check stats with `/level`, and view the leaderboard with `/levelleaderboard`. |

## 🚀 Getting Started

### Requirements

- Python 3.11 or newer
- A Discord bot application and bot token
- A MongoDB connection string
- FFmpeg available on your system for voice playback

### 1. Download the project

```bash
git clone https://github.com/kulisekdev/Synapse.git
cd Synapse
```

You can also download the repository as a ZIP from GitHub.

### 2. Install dependencies

Install the Python packages used by the project:

```bash
pip install discord.py pymongo python-dotenv requests
```

Voice playback may also require FFmpeg and the appropriate voice dependencies for your platform.

### 3. Configure environment variables

Create a local `.env` file in the project root. Never commit this file or share its contents.

```env
mongodb=your_mongodb_connection_string
tkn=your_production_bot_token
testing=your_test_bot_token
webhook=your_error_reporting_webhook_url
```

These are the environment variable names the bot currently reads. Keep bot tokens, database credentials, and webhook URLs private. A separate test bot is useful while developing.

### 4. Customize the configuration

- Review `BotSettings.json` and set the command prefix, owner ID, reconnect behavior, testing mode, and unwanted-link list.
- Open `main.py` and find the server, channel, and role IDs. Replace the hardcoded IDs with IDs from your own Discord server.
- Check the bot's permissions, role hierarchy, and enabled intents in the Discord Developer Portal.
- Review the commands and event handlers so they match how you want your server to work.

**Don't run it unchanged and expect it to work on your server.** It was configured for mine, so expect to do some editing and testing.

### 5. Run the bot

```bash
python main.py
```

## 💬 Commands

| Command | Type | Description |
| --- | --- | --- |
| `/level` | Slash | View your level and XP, or another member's stats. |
| `/levelleaderboard` | Slash | Show the top five users by level. |
| `/verify` | Slash | Assign the configured member role. |
| `/purge <amount>` | Slash | Remove recent messages; restricted by the bot's owner check. |
| `/ban <user> [reason]` | Slash | Ban a member; restricted by the bot's owner check. |
| `!question <question>` | Prefix | Get a random answer. |
| `!flashdance` | Prefix | Play the anthem in your voice channel. |

The prefix is configurable in `BotSettings.json`; `!` is shown as the example/default used in the code.
